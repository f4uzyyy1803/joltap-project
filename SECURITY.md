# Безопасность и ключи

## Где живут ключи

| Ключ | Где хранится | Уходит ли в git | Уходит ли в мобильный бандл |
|---|---|---|---|
| `OPENWEATHER_API_KEY` | `joltap-backend/.env` | ❌ нет | ❌ нет — фронтенд ходит на `/weather`, ключ используется только на сервере |
| `TWILIO_SID` / `TWILIO_TOKEN` | `joltap-backend/.env` | ❌ нет | ❌ нет |
| `DATABASE_URL` / `SYNC_DATABASE_URL` | `joltap-backend/.env` | ❌ нет | ❌ нет |
| `FIREBASE_KEY` | `joltap-backend/.env` | ❌ нет | ❌ нет |
| `EXPO_PUBLIC_MAPTILER_KEY` | `joltap-frontend/.env` | ❌ нет (файл в `.gitignore`) | ✅ да, но это ожидаемо — ключ нужен на устройстве, чтобы загружать тайлы карты. Регистрация в MapTiler — без карты |

## Чек-лист перед первым коммитом / пушем

1. Убедись, что `.env` **нигде** не закоммичен:
   ```bash
   git ls-files | grep -E "\.env$"
   ```
   Если команда что-то вывела — файл уже в истории git, см. раздел "Если ключ уже утёк" ниже.

2. В обеих папках должны быть только `.env.example` (шаблоны без реальных значений), а не `.env`:
   - `joltap-backend/.env.example`
   - `joltap-frontend/.env.example`

3. Проверь `.gitignore` в каждой папке — там уже есть `.env`, `.env.local`, `.env.*.local`.

4. Локально: скопируй шаблон и заполни своими значениями:
   ```bash
   cp joltap-backend/.env.example joltap-backend/.env
   cp joltap-frontend/.env.example joltap-frontend/.env
   ```

## Если ключ уже засветился в публичном репозитории

Просто удалить файл и закоммитить — недостаточно, старый коммит с ключом останется в истории git и будет виден на GitHub. Порядок действий:

1. **Сразу отозви/перевыпусти ключ** в личном кабинете сервиса (OpenWeatherMap, MapTiler, Twilio и т.д.) — это единственный по-настоящему надёжный шаг.
2. Уже после этого можно почистить историю git (`git filter-repo` / BFG Repo-Cleaner), но это вторично: если ключ был публичным хотя бы несколько минут, его нужно считать скомпрометированным независимо от чистки истории.

## Ограничение MapTiler-ключа

Хотя ключ предназначен для клиентского использования, в [дашборде MapTiler](https://cloud.maptiler.com/account/keys/) стоит:
- ограничить его по домену/referrer
- следить за квотой (100k тайлов/мес на бесплатном тарифе)
- при необходимости создать отдельный ключ под каждое окружение (dev / prod)
