# JolTap 🦽🗺️

**Навигация, которая видит препятствия, которых не видит Google Maps.**

## Проблема

Для человека на инвалидной коляске или с ограниченной подвижностью обычный маршрут "от точки А до точки Б" — не то же самое, что для пешехода. Высокий бордюр без съезда, яма, гололёд, вход без пандуса или временные дорожные работы могут сделать "короткий" маршрут физически непроходимым — а обычные карты об этом не предупреждают и строят маршрут так, будто этих препятствий не существует.

В Алматы, как и в большинстве постсоветских городов, доступная инфраструктура появляется точечно и без единой карты — маломобильный человек чаще всего узнаёт о непроходимом участке, только когда уже в него упёрся.

## Решение

**JolTap** — мобильное приложение, которое строит маршруты с учётом реальной доступности среды, а не только расстояния:

- 🗺️ **Три типа маршрута** — безопасный, доступный, быстрый — на выбор пользователя
- ⚠️ **Карта опасностей** — бордюры, ямы, гололёд, отсутствие пандусов, показаны прямо на маршруте с уровнем серьёзности
- 📢 **Краудсорсинг** — сами пользователи отмечают новые препятствия, карта дополняется сообществом
- 🆘 **SOS-кнопка** — экстренный вызов с автоматической геолокацией
- 👤 **Персонализация** — тип мобильности, максимальная дистанция, предпочитаемый маршрут сохраняются в профиле

## Как это устроено технически

Мобильное приложение (React Native / Expo) обращается к бэкенду на FastAPI, который строит маршрут через граф дорог OpenStreetMap (osmnx + networkx, поиск A*), обогащает его данными об опасностях из PostgreSQL/PostGIS и краудсорсинговых репортов пользователей.

```
joltap/
├── JolTapApp/       ← Фронтенд (React Native + Expo)
└── joltap-backend/  ← Бэкенд (FastAPI + PostgreSQL/PostGIS)
```

**Стек:** React Native (Expo 54), FastAPI, PostgreSQL + PostGIS, osmnx/networkx, SQLAlchemy (async), Twilio.

### API

| Метод | URL | Описание |
|---|---|---|
| POST | `/route/build` | Построить маршрут (safe/accessible/fast) |
| GET | `/map/hazards` | Опасные зоны рядом с точкой |
| POST | `/map/report` | Сообщить о препятствии (краудсорсинг) |
| POST | `/sos/activate` | SOS-кнопка |
| POST | `/user/profile` | Сохранить профиль пользователя |
| GET | `/user/profile/{id}` | Получить профиль |

## Быстрый запуск

**Бэкенд** (mock-версия, без БД — для теста за 30 секунд):
```bash
cd joltap-backend
pip install -r requirements.txt
uvicorn main:app --reload --host 0.0.0.0 --port 8000
```
Swagger-документация: `http://localhost:8000/docs`

Production-версия с реальной БД (PostgreSQL/PostGIS) и подробности по каждому файлу — в [`joltap-backend/README.md`](./joltap-backend/README.md).

**Фронтенд:**
```bash
cd JolTapApp
npm install
npx expo start
```
Отсканируй QR в приложении **Expo Go** (iOS/Android). Подробности — в [`JolTapApp/README.md`](./JolTapApp/README.md).

## Безопасность

Ключи и креды хранятся в `.env` (не коммитится, см. `.env.example` с шаблоном) и никогда не попадают в мобильный бандл. Подробный чек-лист — в [`SECURITY.md`](./SECURITY.md).
